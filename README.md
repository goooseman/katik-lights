# Там, где свет

Персональный сайт-подарок для Кати.

Статический сайт без сборки. Откройте index.html через локальный веб-сервер.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Прямые переходы: ?chapter=4 — East Brother; ?gift=shore — Cypress Inn.

Фотографии и тексты личные; разрешение на их повторное использование не предоставляется. Авторство фотографий отелей указано на сайте.
